{% comment %} What a figure is, for each kind of report, and where a change goes. {% endcomment %}

{% if method == "by_well" %}Each figure is a well's share of a month's crop ET on the use areas it irrigates. Where someone has set a share on the well's page, OpenH2O uses it; otherwise OpenH2O divides each use area's crop ET the way the by-well report does. The figure is crop ET, not metered pumping.{% elif method == "calwatrs" %}Each figure is a point of diversion's share of a month's crop ET on the use areas it serves. Where someone has set a share on the point of diversion's page, OpenH2O uses it; otherwise OpenH2O divides each use area's crop ET the way the CalWATRS report does. The figure is crop ET, not a measured diversion.{% else %}Each figure is a use area's crop ET for one month: the OpenET Ensemble depth that OpenH2O records, times the use area's acres.{% endif %} Change any figure to match your own records before you file this report.

OpenH2O saves your changes for this page only. {% if submission.report_template.report_type != "gears_by_et" %}The report's download file and the Use Ledger keep the crop ET OpenH2O records. {% endif %}OpenH2O does not submit reports to the state.
