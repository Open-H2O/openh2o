Step Where What to do
{{ steps.pwsid }}Onboard your water system Water Data > Onboard System{% if user_can_write %}
Go to Onboard System →{% endif %}		 Enter your Public Water System ID (PWSID) and OpenH2O looks up EPA’s Envirofacts record for it: the regulatory details and the facilities. Nothing is written until you review the results and confirm.
Run the Setup Wizard Administration > Setup Wizard{% if 'setup' in enabled_modules and user_can_write %}
Run the Setup Wizard →{% endif %}		 Give it your district boundary; it does Steps {{ wizard_cited_steps }} for you and part of Step {{ steps.zones }}, so run it before them.
{{ steps.zones }}Define management zones Administration > Zones
Go to Zones →		 {% if 'setup' in enabled_modules %}The wizard adds the DWR Bulletin 118 subbasins that cross your boundary as zones; create{% else %}Create{% endif %} your own management zones{% if 'accounting' in enabled_modules %}, each with its own allocation ceiling{% endif %}{% if 'parcels' in enabled_modules %}, and put each use area in one once it is imported{% endif %}{% if 'accounting' in enabled_modules %}; at least one zone must exist before you can allocate water{% endif %}.
{{ steps.use_areas }}Import your use areas Water Data > Use Areas
Go to Use Areas →		 {% if 'setup' in enabled_modules %}The wizard brings them in from the statewide parcel layer; to use your own, upload{% else %}Upload{% endif %} use area boundaries from your county GIS department as GeoJSON or Shapefile. Each needs an Assessor Parcel Number (APN).
{{ steps.wells }}Import your wells Water Data > Wells
Go to Wells →		 Upload well locations from CSV or Shapefile, each with coordinates and a state well number or local ID.
{{ steps.surface }}{% if 'recharge' in enabled_modules %}Add surface diversions and recharge areas{% else %}Add surface diversions{% endif %} Water Data > Surface Diversions{% if 'recharge' in enabled_modules %} and Recharge Areas{% endif %}
Go to Surface Diversions →{% if 'recharge' in enabled_modules %}
Go to Recharge Areas →{% endif %}		 Record surface water rights with their points of diversion{% if 'recharge' in enabled_modules %}, and each event at your recharge areas{% endif %}.
{{ steps.stations }}Connect monitoring stations Water Data > Monitoring Stations
Go to Monitoring Stations →		 Switch on Syncing for the stations you want{% if 'setup' in enabled_modules %} among those the wizard found near your boundary{% endif %}, or link a CDEC, USGS or CIMIS station yourself with Add station; readings are then pulled automatically.
{{ steps.accounts }}Set up water accounts Administration > Accounts
Go to Water Accounts →		 Create a water account for each farm, ranch or other unit you track, to group its use areas.
{{ steps.water_year }}Create a water year Administration > Water Years
Go to Water Years →		 Set the window the accounts run over; most agencies use October 1 through September 30.
{{ steps.ceilings }}Set allocation ceilings Administration > Allocations
Go to Allocations →		 An allocation ceiling is the total volume assigned to a zone for a reporting period. Set one for each zone, water type and period.
{{ steps.ledger }}Enter use ledger data Water Data > Use Ledger
Go to Use Ledger →
View the Methodology →		 Record each use area’s rows, by hand or from a CSV; a delivery, a meter reading or an estimate is a usage row (negative), a credit is positive. The platform can also write an estimated usage row from satellite evapotranspiration (ET), as set on Administration > Methodology.
