How to set up OpenH2O

{% if 'setup' in enabled_modules and user_is_admin %}

To try OpenH2O first, choose the demonstration data when the Setup Wizard asks how to start, and remove it before you add your own records.

{{ steps.pwsid }}Add your water system Water Data > Add a water system{% if user_can_write %}
Go to Add a water system →{% endif %}		 If you run a public water system, enter its Public Water System ID (PWSID). OpenH2O finds the system and its facilities in EPA’s Envirofacts database and shows you EPA’s record. OpenH2O saves the record when you confirm it.
Run the Setup Wizard Administration > Setup Wizard{% if user_can_write %}
Run the Setup Wizard →{% endif %}		 The Setup Wizard’s populate step needs a boundary, which is the outline of the land your records cover. Upload the boundary as a zipped shapefile, a KML file or a GeoJSON file, or type the north, south, east and west edges of a rectangle around the land. Or choose Start without one, and come back to the boundary later. From the boundary, the wizard brings in the groundwater subbasins{% if 'parcels' in enabled_modules %}, parcels{% endif %}{% if 'datasync' in enabled_modules %}, streams and monitoring stations{% else %} and streams{% endif %} inside it and nearby. Before it starts, you choose which of these to bring in. The subbasins{% if 'parcels' in enabled_modules %} and parcels{% endif %} come from the California Department of Water Resources, so the wizard finds none outside California. Run the wizard before Step{{ wizard_cited_count|pluralize }} {{ wizard_cited_steps }}, because it does part of {% if wizard_cited_count > 1 %}each of those steps{% else %}that step{% endif %}.
{{ steps.zones }}Create management zones Administration > Zones
Go to Zones →		 {% if 'setup' in enabled_modules %}The Setup Wizard creates a zone for each groundwater subbasin that overlaps your boundary. Draw any other zones you use on the map.{% else %}Draw your zones on the map.{% endif %}{% if 'parcels' in enabled_modules %} After Step {{ steps.use_areas }}, assign each use area to its zone.{% endif %}{% if 'accounting' in enabled_modules %} Each allocation ceiling in Step {{ steps.ceilings }} applies to one zone.{% endif %}
{{ steps.use_areas }}Import your use areas Water Data > Use Areas
Go to Use Areas →		 OpenH2O keeps its records by use area, and each parcel is one use area. {% if 'setup' in enabled_modules %}The Setup Wizard brings in every parcel that overlaps your boundary, with its Assessor Parcel Number (APN), from the California Department of Water Resources’ parcel map, which covers all 58 counties. To load your own parcel file instead, run the import_parcels command on the server.{% else %}To load your parcel file, run the import_parcels command on the server.{% endif %} The file can be a GeoJSON file or a shapefile. Each parcel needs its APN and an outline OpenH2O can read. A parcel with no APN is skipped, and if any outline cannot be read, the command imports nothing and names each parcel it refused.
{{ steps.wells }}Import your wells Water Data > Wells
Go to Wells →		 {% if 'infrastructure' in enabled_modules %}Add wells one at a time with Add well, or many at once with Import, from a CSV file, a zipped shapefile, a GeoJSON file or a KML file.{% else %}To load your wells, run the import_wells command on the server, with a CSV file or a shapefile.{% endif %} Each well needs a name and a location.
{{ steps.surface }}{% if 'recharge' in enabled_modules %}Add surface diversions and recharge sites{% else %}Add surface diversions{% endif %} Administration > Water Rights
Go to Water Rights →
Water Data > Surface Diversions
Go to Surface Diversions →{% if 'recharge' in enabled_modules %}
Water Data > Recharge sites
Go to Recharge sites →{% endif %}		 On Water Rights, add each water right by hand, or import the State Water Board’s water rights list as a CSV file. {% if 'infrastructure' in enabled_modules %}On Surface Diversions, add each point of diversion and link it to its water right.{% endif %}{% if 'recharge' in enabled_modules %} On Recharge sites, {% if 'infrastructure' in enabled_modules %}add each site and choose its zone, then {% endif %}record each recharge event on the site’s page. Recharge at a site without a zone is not recorded in a basin recharge pool, and the zone can be set later on the site’s page.{% endif %}
{{ steps.stations }}Connect monitoring stations Water Data > Monitoring Stations
Go to Monitoring Stations →		 {% if 'setup' in enabled_modules %}The Setup Wizard adds the stations it finds near your boundary and leaves syncing off for each one. {% endif %}Switch syncing on for each station you want to follow, or add a station with Add station. OpenH2O then collects new readings from those stations on your server’s schedule.
{{ steps.accounts }}Set up water accounts Administration > Accounts
Go to Water Accounts →		 Create a water account for each farm unit{% if 'surface' in enabled_modules %}, place of use or water right{% else %} or place of use{% endif %} you track, and assign its use areas on the account’s page.
{{ steps.water_year }}Create a water year Administration > Water Years
Go to Water Years →		 Create each water year with its start and end dates. A water year starts on the first day of a month and ends on the last day of a month. Before you set the first allocation ceiling, set the month your water year starts in on Delivery Settings. The default is October.
{{ steps.ceilings }}Set allocation ceilings Administration > Allocations
Go to Allocations →		 Set an allocation ceiling in acre-feet for each zone, water type and water year.
{{ steps.ledger }}Record water use Water Data > Use Ledger
Go to Use Ledger →		 Record meter readings, deliveries and adjustments one at a time with New entry, or many at once with Upload CSV. OpenH2O files each entry under the water year that includes its date. An entry counts as groundwater only when its water type is groundwater, when it is a Meter Reading with no water type, {% if 'wells' in enabled_modules %}when its source type is Calculated, or when its source type is ET Estimate and the use area has a well{% else %}or when its source type is Calculated{% endif %}. OpenH2O calculates each month’s figures for a water year when you press Run the calculation on that water year’s page, and every night once your server’s scheduled jobs are installed.{% if 'wells' in enabled_modules %} For each use area that has a well and no meter reading, OpenH2O enters the use area’s ETAW met by groundwater on the Use Ledger.{% endif %}
