How to set up OpenH2O

Step Where What to do
{{ steps.pwsid }}Add your water system Water Data > Add a water system{% if user_can_write %}
Go to Add a water system →{% endif %}		 Enter your Public Water System ID (PWSID), and OpenH2O looks up the water system and its facilities in EPA’s Envirofacts database. OpenH2O saves nothing until you review EPA’s record and confirm it.
Run the Setup Wizard Administration > Setup Wizard{% if user_can_write %}
Run the Setup Wizard →{% endif %}		 Give the Setup Wizard the boundary of the area you manage water for, as a zipped shapefile, KML or GeoJSON file, or type the north, south, east and west limits of a rectangle around that area. The wizard then brings in the groundwater subbasins{% if 'parcels' in enabled_modules %}, parcels{% endif %}{% if 'datasync' in enabled_modules %}, streams and monitoring stations{% else %} and streams{% endif %} in and around your boundary. You choose which of these the wizard brings in before it starts. Run the Setup Wizard before Step{{ wizard_cited_count|pluralize }} {{ wizard_cited_steps }}, because the wizard does part of the work in {% if wizard_cited_count > 1 %}each{% else %}it{% endif %}.
{{ steps.zones }}Create management zones Administration > Zones
Go to Zones →		 {% if 'setup' in enabled_modules %}The Setup Wizard adds each DWR Bulletin 118 subbasin that overlaps your boundary as a zone. Draw any other management zones on the map{% else %}Draw your management zones on the map{% endif %}{% if 'parcels' in enabled_modules %}, and assign use areas to each zone after Step {{ steps.use_areas }}{% endif %}.{% if 'accounting' in enabled_modules %} Every allocation ceiling set in Step {{ steps.ceilings }} belongs to one zone.{% endif %}
{{ steps.use_areas }}Import your use areas Water Data > Use Areas
Go to Use Areas →		 {% if 'setup' in enabled_modules %}The Setup Wizard brings in each parcel that overlaps your boundary from DWR’s statewide assessor parcel layer, with its Assessor Parcel Number (APN). OpenH2O calls each of these parcels a use area. To use your own parcel file instead, load it with the import_parcels command.{% else %}Load your parcel file with the import_parcels command.{% endif %} The file can be GeoJSON or a shapefile, with an APN for each parcel.
{{ steps.wells }}Import your wells Water Data > Wells
Go to Wells →		 Add each well with Add well, or many at once with Import from a CSV, zipped shapefile, GeoJSON or KML file. Each well needs a name and a location.
{{ steps.surface }}{% if 'recharge' in enabled_modules %}Add surface diversions and recharge sites{% else %}Add surface diversions{% endif %} Administration > Water Rights
Go to Water Rights →
Water Data > Surface Diversions
Go to Surface Diversions →{% if 'recharge' in enabled_modules %}
Water Data > Recharge sites
Go to Recharge sites →{% endif %}		 Import your water rights from the State Water Board’s rights list (CSV) on Water Rights, or add each right by hand. Add each point of diversion on Surface Diversions and link it to its water right.{% if 'recharge' in enabled_modules %} Add each recharge site on Recharge sites, and record each recharge event on the site’s page.{% endif %}
{{ steps.stations }}Connect monitoring stations Water Data > Monitoring Stations
Go to Monitoring Stations →		 {% if 'setup' in enabled_modules %}The Setup Wizard adds the stations it finds with syncing switched off. {% endif %}Switch on syncing for the stations you want, or add a station yourself with Add station. OpenH2O then pulls new readings for each of those stations on your server’s schedule.
{{ steps.accounts }}Set up water accounts Administration > Accounts
Go to Water Accounts →		 Create a water account for each farm unit{% if 'surface' in enabled_modules %}, place of use or water right{% else %} or place of use{% endif %} you track, and assign its use areas on the account’s page.
{{ steps.water_year }}Create a water year Administration > Water Years
Go to Water Years →		 Create each water year with its start and end dates.
{{ steps.ceilings }}Set allocation ceilings Administration > Allocations
Go to Allocations →		 Set an allocation ceiling in acre-feet for each zone, water type and water year.
{{ steps.ledger }}Record water use Water Data > Use Ledger
Go to Use Ledger →		 Record meter readings, deliveries and adjustments one at a time with New entry, or many at once with Upload CSV. OpenH2O calculates each month’s figures for a water year when you press Run the calculation on that water year’s page, and every night when your server’s scheduled jobs are installed.{% if 'wells' in enabled_modules %} OpenH2O records on the Use Ledger the ETAW met by groundwater that it calculates for each use area with a well and no meter reading.{% endif %}
