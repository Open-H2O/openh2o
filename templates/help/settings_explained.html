Settings that change a figure

{% if 'wells' in enabled_modules %}{% endif %}
Setting How it works
Calculation steps OpenH2O calculates each month’s figures by following the steps listed on {% if 'accounting' in enabled_modules %}Methodology Settings{% else %}Methodology Settings{% endif %}. An administrator can reorder those steps or switch any of them off.
Effective precipitation {% if 'accounting' in enabled_modules %}Methodology Settings{% else %}Methodology Settings{% endif %} also sets the method for estimating effective precipitation: all of the month’s rain, a fixed percentage of it, or the USDA-SCS soil-storage method, which is the default.
Lowest remainder A step on {% if 'accounting' in enabled_modules %}Methodology Settings{% else %}Methodology Settings{% endif %} sets the lowest value the remainder can fall to, zero acre-feet unless an administrator changes it.
Irrigation efficiency Each field’s irrigation efficiency comes from its irrigation method on file. A field with no irrigation method on file uses the default efficiency on {% if 'accounting' in enabled_modules %}Delivery Settings{% else %}Delivery Settings{% endif %}, 75 percent unless an administrator changes it.{% if 'surface' in enabled_modules %} OpenH2O uses the same irrigation efficiency for a field’s surface water and its groundwater.{% endif %}
The surplus When effective precipitation and the delivery times irrigation efficiency together exceed crop ET, OpenH2O sets the remainder to zero and records the surplus in two parts: effective precipitation in excess of crop ET, and surface water in excess of ETAW.
Surface water in excess of ETAW A setting on {% if 'accounting' in enabled_modules %}Delivery Settings{% else %}Delivery Settings{% endif %} determines how OpenH2O treats surface water in excess of ETAW. By default, OpenH2O credits that water to no one. An administrator can instead credit it to the landowner, less a share left in the basin (10 percent by default), or show it as a separate line on the field’s page without crediting it.
Groundwater extraction Where a well has no meter reading, OpenH2O estimates groundwater extraction by dividing ETAW met by groundwater by the field’s irrigation efficiency. OpenH2O records the difference as deep percolation.
Unused allocation At the end of a water year, OpenH2O carries each zone’s unused allocation into the next water year as a credit, unless {% if 'accounting' in enabled_modules %}Delivery Settings{% else %}Delivery Settings{% endif %} is set to let unused allocation expire.
One zone An administrator can set a different choice for one zone on that zone’s page.
Reporting year When a diversion record file gives a year and a month but no date, a setting on {% if 'accounting' in enabled_modules %}Delivery Settings{% else %}Delivery Settings{% endif %} decides which calendar month each record belongs to: a water year starting in October, a calendar year, or a season starting in a month an administrator chooses.

When sign-in is required, only an administrator can change the settings on this page.

Settings that change no figure

Setting How it works
Record addresses {% if 'accounting' in enabled_modules %}Delivery Settings{% else %}Delivery Settings{% endif %} also sets the web address that each record’s permanent address is published under.
Sign-in Whether sign-in is required is set in the server’s configuration, not on a screen, and changes no figure.

What a change does to the months

Setting How it works
Past months Each calculated month stores the settings it was calculated with. A changed setting affects a past month only when that month is recalculated.
Year-end choice A change to the year-end choice takes effect the next time the carry-over is written.
Reporting year A change to the reporting year applies to files imported after the change, and records already imported keep their months.
