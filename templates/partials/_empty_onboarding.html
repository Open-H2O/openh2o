{% comment %} Actionable empty state (E6) — shown when a list has zero records AND no active search/filter, i.e. a genuine "nothing here yet" moment rather than "no matches." It turns a dead end into the next step: • Fresh instance (needs_setup) → the Setup Wizard, which auto-imports parcels, wells, basins and nearby stations. The wizard is the onboarding spine, so an empty list defers to it. • Configured instance → this screen's own Add + Import actions (the same links its toolbar offers), so an admin who emptied a list can refill it. Caller supplies: `what` (one-line plain-English description of the entity), `add_label` (e.g. "+ Add Well"), and `type_param` (the infrastructure ?type= value). The entity icon stays in the caller so each screen keeps its own glyph. **`type_param` is REQUIRED and must name a type in `infrastructure.views.ADD_TYPE_ORDER`.** This comment used to say it could be "blank for Use Areas, which the add form keys differently", and that sentence was false: there is no parcel type, so a blank one fell through `_supported_type` to `ADD_TYPE_ORDER[0]` and both buttons opened the Add Well form on a screen listing use areas. Phase 119 removed that include and the Water Rights one. Only wells and recharge include this partial now, and `tests/test_page_offers_what_it_lists.py` fails any page that includes it with a type its list does not carry. {% endcomment %}
