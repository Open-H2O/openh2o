What Brought in from EPA Left for you
Water system Name, status, system type, owner type, primary source and mailing address; a second lookup refreshes them State classification and regulating agency; a lab import fills the agency
Facilities Each facility EPA carries with a state-assigned facility ID Nothing; a facility without that ID is left out, and the review names it
Sampling points None; EPA's record carries none Each point your lab file names, added after you confirm
Population and service connections EPA's total for each The breakdowns by category. EPA sends one total for each, so those fields stay empty until a source that breaks them down is imported.
Compliance Nothing; EPA's SDWIS extract is a federal copy, not the primacy agency's authoritative file Not determined here; nothing compares a system against a requirement
Links to wells None Set on each facility's page under Facilities, with Edit local name; a second lookup never changes a link already made
