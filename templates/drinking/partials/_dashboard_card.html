{% comment %} Each count links to the page that holds the rows behind it, in the same shape drinking/overview.html already uses: the VALUE is the link, styled `.data-table-link`, and the label above it stays plain. A count that names a page the operator cannot get to from it is a dead end, and this card is the first drinking-water thing most people see. The date links to Sample results too — the same destination as the count beside it, because the question "which sample was that?" is answered by the same list — but only when there IS a date. With none, `|blank` renders "Not recorded", and wrapping that in a link would advertise a record to open. The counts carry `|intcomma`, which this card did without until now. The note in drinking/overview.html recorded that as a scope decision — that page got separators, "the dashboard card is a different surface and was left alone" — and the reasoning it gave applies here too, harder: an unseparated five-digit number beside two-digit ones reads as an oversight, and on THIS page it also sits under account and zone tables where every figure is separated.
