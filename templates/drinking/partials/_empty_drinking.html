Deliberately NOT `partials/_empty_onboarding.html`: that partial routes an operator to the Setup Wizard or to infrastructure's Add/Import screens, and neither of those knows anything about water systems, sampling points or lab results. Pointing there would be a dead end wearing a helpful coat. This links the lab-file import, but only where it is actually the answer. The importer creates sample events and results; it deliberately never creates a water system, a facility or a sampling point, because inventing system structure from a lab file would let a typo manufacture a monitoring location. So an empty RESULTS page offers the import, and the empty system and sampling-point pages honestly do not: importing a lab file there would produce nothing but a page of row errors. The same idea holds for the system page. An operator with no water system at all is looking at the one screen where onboarding IS the answer, so that page — and only that page — offers it. The sampling-point and results pages still do not: onboarding creates a system and its facilities and deliberately never creates a sampling point. The third door is the point builder, and the two wrong ones are closed. The `{% else %}` branch below does not send an operator to the Django admin, a screen that is not the answer and that most operators cannot reach. No caller reaches that branch (each sets one of the three flags); it says plainly that no screen adds the record. The facilities page is a flag flip: onboarding is what writes a system AND its facilities, so it gets `onboard_link`. The sampling-points page is not, which is why it needed a branch of its own. Onboarding creates facilities and deliberately never creates a sampling point, so the right door there is the point builder — and the builder takes a PWSID in its path. When no system exists there is no PWSID to give, and the honest destination is onboarding: build the system first, then its points. That is the fallback, and it is a real state rather than a defensive `if` — a fresh deployment has no system and an empty sampling-point list at the same moment.
