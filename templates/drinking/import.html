What OpenH2O saves from a lab file

Case What OpenH2O does
Sample events and results OpenH2O imports each row that has no error, unless the same result is already on file or appears earlier in the file.
New analytes OpenH2O adds any analyte in the file that is not already on file. The preview lists each new analyte.
Sampling points and facilities OpenH2O never adds a sampling point or a facility from a lab file. Add a missing sampling point first, then upload the file again.
A result already on file OpenH2O skips the row, so importing the same file again does not add that result a second time. For a result imported before OpenH2O kept a lab file’s MCL and DLR, OpenH2O adds this file’s MCL and DLR.

Columns OpenH2O reads

OpenH2O matches each column by its name, so the Division of Drinking Water’s file does not need any column matching. OpenH2O reads only the columns listed below.

Column Required What it holds
PS Code Yes The sampling point where the sample was taken. The point must already be on file.
Sample Date Yes The date the sample was collected, written YYYY-MM-DD, MM-DD-YYYY or M/D/YYYY.
Analyte Name Yes OpenH2O matches an analyte on file by Analyte Code first, then by Analyte Name.
Result Yes A number, a value below the reporting level such as <0.005, or P or A for present or absent. The cell can be blank when Less Than Reporting Level is Y and Reporting Level gives the level.
Sample Time No The time the sample was collected. When OpenH2O cannot read the time, OpenH2O imports the result without a time and notes the row on the preview.
Sample Type No RT, RP, SP or TG, or the name Routine, Repeat, Confirmation, Special or Triggered. OpenH2O records a blank as routine, and any other value as routine with a note on the preview.
Analysis Date No The date the lab analyzed the sample, written YYYY-MM-DD, MM-DD-YYYY or M/D/YYYY.
ELAP Cert# No The lab’s certificate number under California’s Environmental Laboratory Accreditation Program.
Lab Name No Laboratory name
Analyte Code No The Division of Drinking Water’s code for the analyte. When an analyte on file has no code, OpenH2O adds the file’s code to that analyte.
Counting Error (±) No OpenH2O stores the counting error with the result.
Units of Measure No The result’s unit, such as mg/L. OpenH2O copies the unit unchanged.
Less Than Reporting Level No Y marks a result below the reporting level
Reporting Level No OpenH2O stores the reporting level with every numeric result.
Method No Analytical method
Collector No The person who collected the sample. OpenH2O records the collector only for a sample not already on file.
Regulating Agency No OpenH2O records the agency on the water system when the system has none on file and every row names the same agency.
MCL No OpenH2O stores the file’s MCL with the result and does not compare the result with the MCL.
DLR No The detection limit for purposes of reporting. OpenH2O stores the file’s DLR with the result.
