What the import will and will not create

Case What the commit does
Sample events and results Created from every row the preview marks Will create
New analytes Analytes the file names that this system has not seen are added to the vocabulary; the state's file is the authority. The preview lists each one before you commit.
Sampling points and facilities Never created. A PS Code this system does not carry is a row error; add the facility and sampling point first, then import again.
A result already recorded Skipped, so importing the same file again is safe; one recorded before limits were kept gains this file's MCL and DLR
A row with an error Not written; the preview lists it with what is wrong

Columns the file carries

Matched by header, so the state's own file needs no mapping. A file missing a required column is refused before the preview; other columns are ignored.

Column Required What it holds
PS Code Yes Sampling point the sample was taken at; the point must already be on file
Sample Date Yes Date collected, YYYY-MM-DD or MM-DD-YYYY
Analyte Name Yes Analyte, matched by Analyte Code first, then by name
Result Yes A number; a value below the reporting level, such as <0.005; or presence or absence, such as P or A. Blank only with Less Than Reporting Level Y and a Reporting Level.
Sample Time No Time collected; an unreadable time is ignored and noted in the preview
Sample Type No RT, RP, SP or TG (routine, repeat, special, triggered), or a type name such as Confirmation; blank is recorded as routine, any other value as routine with a note
Analysis Date No Date analyzed
ELAP Cert# No Laboratory's certificate number under the Environmental Laboratory Accreditation Program (ELAP)
Lab Name No Laboratory name
Analyte Code No State's analyte code; recorded on an analyte on file that has none
Counting Error (±) No Counting error, stored with the result
Units of Measure No Unit of the result, stored as written, such as mg/L
Less Than Reporting Level No Y marks a result below the reporting level
Reporting Level No Reporting level, stored with a result below it
Method No Analytical method
Collector No Who collected the sample, stored on a new sample event
Regulating Agency No Recorded on the water system when its own field is blank and every row names the same agency
MCL No Maximum contaminant level the file carries, stored as reported and never compared with the result
DLR No Detection limit for purposes of reporting the file carries, stored as reported
