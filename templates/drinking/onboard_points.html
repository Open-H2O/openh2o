What this page is for

A lab file names a PS Code on every line. The importer matches that code against the sampling points listed here.

A row naming a code you have not listed is reported and skipped, never guessed at.

A PS Code is three parts — PWSID, facility ID, and a number or short label. You supply only the last part; the first two come from the system and the facility.
