The state's sampling schedule

OpenH2O saves nothing until you press Import on the preview.

Each row names a sampling point by its PS Code. Add the sampling points before you import the file.

When a row's sampling point and analyte are already on the schedule, the preview lists each change before OpenH2O saves it.

OpenH2O saves each row's GROUP and NOTES in the notes of a new schedule row. On a row already on the schedule, OpenH2O changes only the frequency, Last done and Next due.

Columns OpenH2O reads

Column Required What it holds
PSCODE Yes The sampling point's PS Code. A sampling point with this code must be on the site.
ANALYTE CODE No The Division of Drinking Water's four-digit analyte code. OpenH2O looks for the analyte by this code first.
ANALYTE Yes The analyte's name. When no analyte on the site has the code or the name, OpenH2O shows the name under What is sampled.
FREQ MONTHS Yes The number of months between samples. OpenH2O saves 1, 3, 12, 36, 72, 108 and 120 months as Monthly, Quarterly, Annual, Every 3 years, Every 6 years, Every 9 years and Every 10 years. OpenH2O saves any other number as Other. A new schedule row then gives the months in its notes.
LAST SAMPLE No The last sample's date in the form M/D/YYYY.
NEXT SAMPLE DUE Yes The next sample's due month in the form YYYY/MM. OpenH2O keeps it as a month.
GROUP No Saved in the row's notes.
NOTES No Saved in the row's notes after the group.

OpenH2O does not read the file's other columns. Lab results come in through Import lab results.
