Upload a boundary file

{% csrf_token %}

Drag and drop a zipped shapefile (.zip), a KML (.kml) or a GeoJSON (.geojson or .json) file here, or click to browse.

When the file holds several polygons, OpenH2O combines them into one boundary.

OpenH2O reads a shapefile's projection from the .prj file in its zip and converts the coordinates to WGS84 longitude and latitude when needed. A KML or GeoJSON file is read as WGS84.
