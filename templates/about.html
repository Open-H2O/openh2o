OpenH2O

{% module_nouns "measurements:measurements" "accounting:deliveries" "wells:wells" "surface:surface diversions" "recharge:managed aquifer recharge" "accounting:mixed-use accounting" as data_nouns %}

OpenH2O is open-source software for California water agencies. It keeps an agency's {{ data_nouns }} in one system that the agency runs and owns. An agency can install it on its own computer or server, and an AI coding assistant can do the installation from the code on GitHub.

Who OpenH2O is for

Who What OpenH2O does for them
A groundwater agency or an irrigation district OpenH2O maps its {% module_nouns "parcels:use areas" "wells:wells" "accounting:water accounts" %}, keeps a monthly ledger and works out a water balance for each field.
A ditch company or a surface-water diverter OpenH2O keeps its water rights, points of diversion and monthly diversion records, and writes them in the state's report layout.
A small public water system OpenH2O keeps its facilities, sampling points, lab results and production records.
An agency that watches public gauges OpenH2O reads public monitoring stations and shows when each one last reported.
A recharge operator OpenH2O keeps its recharge sites, each recharge event and its measurements.

OpenH2O does not submit reports to the state. It writes the figures in the state's layouts, and the agency files them.

Where the accounting method comes from

What The fact
The method OpenH2O uses the accounting method of the Groundwater Accounting Platform, an open-source system built by ESA (formerly Sitka Technology Group) and stewarded by the California Water Data Consortium.
The code OpenH2O is separate code, written in Python. None of the Groundwater Accounting Platform's code is copied into it.
The license Both are released under the GNU Affero General Public License, version 3.

Who made OpenH2O

What The fact
Author Brent Vanderburgh wrote OpenH2O and maintains it.
Source code The code is at github.com/Open-H2O/openh2o. Under its license, anyone who changes the code and runs it for other people must give those people the changed code.
Built with Django, PostGIS, MapLibre GL JS, HTMX and Docker, all open source
Third-party licenses Third-party licenses and notices lists each library OpenH2O uses and its license.
Demonstration data What is real in this demonstration lists which records are public and which are invented.
