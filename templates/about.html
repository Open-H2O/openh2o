Where OpenH2O comes from

OpenH2O's water accounting is modeled on the Groundwater Accounting Platform, which ESA (formerly Sitka Technology Group) develops with the support of the California Water Data Consortium.

OpenH2O is a separate program, written from scratch in Python.

Earlier versions of the Groundwater Accounting Platform ran at the Rosedale-Rio Bravo Water Storage District and at Nebraska's Natural Resources Districts.

OpenH2O reads satellite estimates of evapotranspiration (ET) from OpenET and station readings from public sources such as CDEC and USGS.

Who made OpenH2O

Author Brent Vanderburgh wrote OpenH2O and maintains it.
Source code The source code is on GitHub at github.com/Open-H2O/openh2o.
License OpenH2O is released under the GNU Affero General Public License, version 3.
Built with OpenH2O is built on open-source software, including Django, PostGIS, MapLibre GL JS, HTMX and Docker.
Libraries OpenH2O lists the license of every library it uses in the third-party notices file on GitHub.
