Columns OpenH2O reads

Column Required What it holds
APPLICATION_NUMBER Yes The right's application number. OpenH2O skips a row whose application number is already on file.
WATER_RIGHT_TYPE Yes The right type. OpenH2O adds any right type not yet on file, spelled as the file spells it.
PRIMARY_OWNER_NAME Yes Holder
WATER_RIGHT_STATUS No OpenH2O copies the right's eWRIMS status unchanged.
SOURCE_NAME No OpenH2O copies the source unchanged.
WATERSHED No OpenH2O copies the watershed unchanged.
FACE_VALUE_AMOUNT No Face value, acre-feet per year
FACE_VALUE_UNITS No OpenH2O keeps the face value only when this column reads Acre-feet per Year. Otherwise OpenH2O imports the right without its face value.
MAX_DD_APPL No Maximum rate, cfs
MAX_DD_UNITS No OpenH2O keeps the maximum rate only when this column reads Cubic Feet per Second. Otherwise OpenH2O imports the right without its maximum rate.
PRIORITY_DATE No Priority date, YYYY-MM-DD or M/D/YYYY
LICENSE_ID No License number
PERMIT_ID No Permit number
USE_CODE No Purpose of use
USE_NET_ACREAGE No Net acreage, acres
DIRECT_SEASON_START_MONTH_1
DIRECT_DIV_SEASON_START_DAY_1
DIRECT_DIV_SEASON_END_MONTH_1
DIRECT_DIV_SEASON_END_DAY_1		 No Direct diversion season, start and end month and day as numbers
STORAGE_SEASON_START_MONTH_1
STORAGE_SEASON_START_DAY_1
STORAGE_SEASON_END_MONTH_1
STORAGE_SEASON_END_DAY_1		 No Storage season, start and end month and day as numbers

OpenH2O does not read the export's other columns and does not convert any unit.
