Columns run Month, Diverted, Return flow, Retained, Type -- rule 1, the equation's own order -- with ONE .col-sep on Retained (rule 3: the kind of number changes there, from what the operator recorded to what the platform worked out) and no Period column: the row-group dividers below say the water year once per group (rule 7) instead of repeating it on every row. Retained/To storage, never "consumed" (DESIGN.md copy rule 12) -- the Type cell carries the return-flow badges beside the diversion type, not wrapped inside the Retained figure. An Actions column ends each row a writer can act on with the "..." menu (partials/_row_menu.html): Edit, Correct this record, then Void this record. Edit swaps this whole section in for a row's own "Edit diversion record" form (edit_record / edit_form below); Void this record opens the reason row under the record (core:record_void) and the section comes back with the record struck and one line under it. A record is never deleted: its figures leave the totals and the water year's count, and it stays in date order. A corrected record is struck the same way, with the corrected one directly above it. A finalized water year's header ends in "Finalized" for every role; its rows hold a menu (Correct this record, Void this record, no Edit) for an administrator only. A "How known" column carries the method label, the device nickname when one is set, and the data state as a small word -- the state's own vocabulary (23 CCR 934(b), 931(s)/(j)(3)) rather than this platform inventing one. The rule version that governs the record's month (2016 rule vs the 2026 rewrite) is derived and rarely needed, so it rides the row's own `title` attribute instead of taking a column of its own. {% endcomment %}
